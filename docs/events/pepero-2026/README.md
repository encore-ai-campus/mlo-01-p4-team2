## 확인 기준

- 참여·미션 실적은 매니저용 뉴스레터, 설문 결과는 만족도 보고서 기준.

- 인프라 담당 조성현, 만족도 조사 담당 강한솔, 경품 지급 담당 수현 매니저님.

- 별도 보관 자료·내부 대시보드는 저장소 첨부 자료와 구분.
