## 5. 부록

### 5-1. 지표 정의·집계 기준

| 지표 | 집계 기준 |
|---|---|
| 장애 건수 | 같은 원인으로 연속 발생한 오류를 한 사건으로 집계. 오류 기록·덤프·실패 작업의 단순 합산 제외 |
| 평균 복구 시간 | 발생·서비스 정상화 시각이 모두 확인된 사건의 복구 시간 평균. 제외 사건·사유 별도 표기 |
| 영향 계정 수 | 실제 실패·오류 영향이 확인된 고유 계정 수 |
| 최종 조치 완료율 | 기술 복구와 필요한 안내·기록 정정·경품 조치까지 종료한 장애 ÷ 전체 장애 × 100 |
| 대시보드 수집 상태 | 모니터링 지표 수집 여부. 서비스 기능 정상·데이터 누락·중복 검증과 구분 |
| 예상 AWS 절감액 | EC2 대체 운영 예상액 − 기존 구성의 예상 AWS 비용 |
| 예상 AWS 절감률 | 예상 AWS 절감액 ÷ EC2 대체 운영 예상액 × 100 |

분모가 0이거나 필요한 기록이 없는 경우 산출 불가 또는 해당 없음으로 표기. 미집계를 0건·0명으로 처리하지 않음.
