# 2. KPI 및 실적

## 2-1. 방문·등록·완료 실적

참여·완료 실적은 매니저용 뉴스레터 적용. 이전 11.11 DB 조회 수치는 본문 실적에서 제외. [S1]

| 지표 | 목표 | 실적 | 평가 |
|---|---:|---:|---|
| 11~12일 활동 기록 기준 방문 고유 계정 | 80명 | 66명 | 목표 대비 82.5%, 14명 부족 |
| 11일 활동 기록 기준 방문 고유 계정 | 미설정 | 59명 | 당일 이용 실적 |
| 메인 미션 참여 등록 | 40명 이상 | 63명 | 달성, 목표 대비 157.5% |
| 메인 미션 완료 | 별도 목표 없음 | 49명 | 최종 전달 완료 기준 |
| 메인 미션 완료율 | 50% 이상 | 77.8% | 달성, 49 ÷ 63 × 100. 목표보다 27.8%p 높음 |
| 전반 만족도 | 4.0/5 이상 | 4.31/5 | 달성. 상세 결과 2-4 참조 |
| 장애 최종 조치 완료율 | 90% 이상 | 산출 보류 | 장애 목록·최종 종료 상태 보완 필요 |

방문 실적은 뉴스레터의 **활동 기록 기준**. 접속 세션 기준과 구분. 현재 운영명세의 방문 평가 구간은 11.11~12 14:00이며, 초기 기획서·템플릿의 11.09~12 구간과 차이. 본문의 목표 비교는 뉴스레터 실적 66명 적용. 초기 구간 기준 실적은 별도 집계 필요. [S1, S4]

등록 기준은 꾸왕이 NPC 클릭 → 대사창 표시 → 「단서 확인·조사 시작」 버튼 클릭. 완료 기준은 꾸왕이에게 최종 전달 완료. 활동·등록·완료는 서로 다른 기록으로, 활동 계정 59명과 등록 63명을 동일 분모로 비교하지 않음.

뉴스레터의 미션 집계 시작·종료 시각과 관리자 포함 범위는 상세 표기 부족. 63명·49명은 뉴스레터 확정 수치로 사용하되, 11.11 20:00만을 필터링한 독립 재집계로 표현하지 않음.

**미확인:** 11.09·10·12 일별 방문, 공식 등록 시각 기준 완료 소요 시간의 평균·중앙값·최단·최장, 관리자 제외 실적.

비교 조건은 서울 Linux 온디맨드, 추가 c7i.12xlarge 2대·t3.large 6대, 연속 85.5시간 또는 운영시간·야간 합계 64.5시간. 추가 gp3 240GiB는 두 안 모두 85.5시간 보유, 환율 1,400원/달러·부가세 10%, 100원 단위 반올림.

기존 AWS의 행사 전 구축비와 네트워크 공유 가정은 양쪽 동일 적용. 홈서버 전기료·감가상각·추가 데이터 전송료 제외. 성능 동등성 실측이 없는 비용 시나리오로, 확정 절감액·전체 인프라 절감률과 구분.

경품 실제 구매액·기타 비용·확정 인프라 비용 부재로 총집행액 산출 보류. 경품 계획 120,090원과 AWS 누적 예상액을 합산해 실제 지출로 제시하지 않음.
