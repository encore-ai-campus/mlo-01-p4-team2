## 수정

- README 충돌은 PostgreSQL 안내와 최신 이벤트 작업 안내를 함께 유지해 해결함.
- 정수 키였던 계정이 UUID로 바뀌면서 근접 확인 티켓의 JSON 직렬화가 실패하는 부분을 수정함. 서명 내용과 계정 비교에 UUID 문자열을 사용하고 다른 계정의 재사용 거절도 검사함.
- 스토리 테스트의 타 계정 위조 티켓도 UUID 문자열로 생성함. 정지 소켓 fixture는 새 Profile·Position 분리 구조를 사용하는 공통 factory로 전환함.
- 기존 PostgreSQL/UUID·위치 분리·포인트·게시판/콘텐츠 기록·CDC 중심 구조를 유지함. 제거된 Outbox 발행 코드나 식단 댓글 기능을 되살리지 않음.
- 이벤트 스토리·관리자 정지 기능과 로컬 맵/UI 변경을 유지함.
