- 정의 보정과 과거 완료 복구를 명시적으로 분리했습니다. 메인 상태 함수는 조회만 합니다.

- 일일 안내는 조회 후 소비합니다. 조회 실패가 일회성 안내를 소모하지 않도록 예외 처리했습니다.
- 저장 이후 응답 조회가 실패하면 저장은 유지됩니다. 재요청해도 최초 시각·접속 UUID·보상을 중복 생성하지 않습니다.
